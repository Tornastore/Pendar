# Mind Bastion — مجموعه بازی‌های فکری

## اتصال چندنفره (وای‌فای محلی)

### مراحل اتصال دو گوشی

1. **هر دو گوشی به یک وای‌فای** وصل باشند (هات‌اسپات یکی هم OK است).
2. روی گوشی اول: بازی را انتخاب کنید → **میزبانی (Host)**
   - IP گوشی روی صفحه لابی نمایش داده می‌شود (مثلاً `192.168.1.12`).
3. روی گوشی دوم: همان بازی → **اتصال (Join)**
   - با صفحه‌کلید عددی IP میزبان را وارد کنید → **اتصال**.
4. وقتی در لابی تعداد بازیکنان به ۲ رسید، Host دکمه **شروع بازی** را می‌زند.
5. هر نفر فقط در نوبت خودش می‌تواند حرکت کند.

### نکات مهم
- فایروال/دیتای موبایل را خاموش کنید؛ فقط وای‌فای.
- اگر IP نشان داده نشد، از تنظیمات وای‌فای گوشی Host آن را پیدا کنید.
- پورت: `7777` (ENet)
- بیشتر بازی‌ها دو نفره هستند؛ کوریدور علاوه بر بازی با کامپیوتر، حالت چهار نفره محلی روی یک دستگاه نیز دارد. اتصال شبکه‌ای کوریدور فعلاً فعال نیست.

## پاسور — قوانین دقیق
- عدد: جمع دقیقاً ۱۱
- شاه↔شاه ، بی‌بی↔بی‌بی
- سرباز: جارو (غیرشاه/بی‌بی)
- سور = ۵ | هفت‌خاج = ۷ | ۱۰♦ = ۳ | ۲♣ = ۲ | آس/سرباز = ۱
- هدف: ۶۲ امتیاز

## اجرا
Godot 4.3+ → Import → Run

## هوش مصنوعی اوتلو ۸×۸ و ۱۲×۱۲
- هر دو اندازه از موتور هوش مشترک `games/othello/ai.gd` استفاده می‌کنند.
- شش درجه سختی از «خیلی آسان» تا «استادتمام» در صفحه انتخاب حالت قابل انتخاب است.
- درجه‌های بالاتر از جست‌وجوی چندحرکتی آلفا–بتا با ارزیابی موقعیت، گوشه‌ها، تحرک، مهره‌های مرزی و مرحله بازی استفاده می‌کنند.
- برای تخته ۱۲×۱۲ سقف محاسبات جداگانه تنظیم شده تا با بزرگ‌تر شدن صفحه، جست‌وجو نامحدود نشود.

## اصلاحات کوریدور
- هر دیوار دو گذر متوالی را مسدود می‌کند و دیوارهای متقاطع/هم‌پوشان پذیرفته نمی‌شوند.
- حرکت پرش و حرکت مورب در شرایط قانونی پیاده‌سازی شده است.
- حالت چهار نفره محلی با ۵ دیوار برای هر بازیکن اضافه شده است.

## نسخه ۱۲ — بازطراحی رابط کاربری
- تم تیره مدرن، کارت‌ها و دکمه‌های گرد با سایه، آیکون‌های برداری، انیمیشن مهره‌ها
- ناوبری پایین (بازی‌ها / آنلاین / رتبه‌بندی / آمار) و فیلتر دسته‌بندی در منو
- دکمه برگشت اندروید و Esc: در بازی → منوی توقف، در منوی اصلی → تأیید خروج
- تأیید دو مرحله‌ای: تسلیم، خروج از بازی، بازی جدید، ترک لابی، خروج از برنامه
- راهنمای هر بازی (بار اول خودکار نمایش داده می‌شود)
- فونت رابط فارسی از `fonts/Vazirmatn-Regular.ttf` و `fonts/Vazirmatn-Bold.ttf` بارگذاری می‌شود. Workflowهای خروجی Web این فایل‌ها را هنگام ساخت از بسته رسمی Vazirmatn (با مجوز SIL Open Font License 1.1) دریافت می‌کنند؛ بنابراین لازم نیست فایل فونت را به مخزن Git اضافه کنید. برای اجرای محلی در Godot نیز این دو فایل را در پوشه `fonts/` قرار دهید.

## معماری ماژولار

ساختار تفکیک‌شده و راهنمای ادامه توسعه در `ARCHITECTURE.md` قرار دارد. منطق و state بازی‌ها در `games/<game_id>/rules.gd`، کاتالوگ در `core/game_catalog.gd` و امتیازدهی/رتبه‌بندی در `services/` قرار گرفته‌اند. برای کنترل ساختاری سریع، از ریشه پروژه دستور `python tools/verify_structure.py` را اجرا کنید.

## خروجی وب و نصب به شکل اپ (PWA)
- preset وب با نام `Web` به `export_presets.cfg` اضافه شده و خروجی آن در `build/web/index.html` قرار می‌گیرد.
- Workflow با نام **Build Web App** در هر push به شاخه `main` خروجی وب می‌سازد. از بخش **Actions**، اجرای موفق را باز کنید و artifact با نام `MindBastion-Web` را دانلود کنید؛ فایل دانلودشده شامل `index.html`، فایل‌های JavaScript/WebAssembly و بسته بازی است.
- برای انتشار خودکار روی GitHub Pages، در **Settings → Pages** منبع را روی **GitHub Actions** بگذارید، سپس در **Actions → Deploy Web App to GitHub Pages → Run workflow** اجرا کنید. لینک سایت در خروجی همان اجرا نمایش داده می‌شود.
- خروجی Web به صورت PWA تنظیم شده و در مرورگر پشتیبانی‌شده امکان نصب روی صفحه اصلی و کش آفلاین دارد. برای اجرای محلی، فایل‌ها را از طریق وب‌سرور باز کنید (مثلاً `python -m http.server 8000` در پوشه خروجی)؛ بازکردن مستقیم `index.html` با `file://` روش قابل اتکایی نیست.
- **محدودیت شبکه:** مرورگرها از ENet/UDP سطح پایین پشتیبانی نمی‌کنند. بنابراین در نسخه وب، میزبانی روی Wi‑Fi، ورود با IP و ساخت اتاق غیرفعال است؛ بازی با کامپیوتر و حالت‌های محلی قابل استفاده‌اند. برای آنلاین واقعی باید ارتباط به WebSocket یا WebRTC و یک سرور سازگار منتقل شود.
- آمار و رتبه‌بندی محلی در مرورگر به مجوز ذخیره‌سازی مرورگر وابسته است؛ در حالت ناشناس یا با مسدودکردن IndexedDB ممکن است ماندگار نباشد.
