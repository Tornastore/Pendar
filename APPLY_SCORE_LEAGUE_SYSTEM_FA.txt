سیستم امتیاز و لیگ ماهانه

1) ZIP را باز کنید و پوشه‌ی MindBastion_Modular را در مسیر کاری پروژه جایگزین کنید؛ پوشه‌ی .git موجود خود را نگه دارید.
2) در ریشه‌ی مخزن اجرا کنید:
   git add -A
   git commit -m "Add fair monthly leagues and game MMR"
   git push origin main
3) در GitHub Actions اجرای Deploy Web App to GitHub Pages را بررسی کنید.

قواعد کلیدی:
- برد +24، مساوی +4، باخت -12 به‌عنوان پایه‌ی امتیاز لیگ، با ضریب بازی و حالت.
- بازی CPU بر اساس سطح سختی امتیاز فصل کمتری می‌دهد؛ CPU رتبه‌ی مهارتی آنلاین را تغییر نمی‌دهد.
- MMR کلی و MMR هر بازی جدا هستند و فقط در بازی آنلاین با انسان تغییر می‌کنند.
- امتیازهای لیگ در شروع ماه میلادی صفر می‌شوند؛ امتیازهای تمام‌دوران و MMR باقی می‌مانند.
- این تغییرات فعلاً در پروفایل محلی ذخیره می‌شوند. جدول جهانی و matchmaking مبتنی بر رتبه هنوز پیاده‌سازی نشده و به ذخیره‌سازی پایدار و ثبت نتیجه در سمت سرور نیاز دارد.

آزمون ساختاری و تست‌های Python جایگزین اجرای Godot نیستند؛ بعد از Push، ساخت واقعی Godot 4.3 را در GitHub Actions بررسی کنید.
