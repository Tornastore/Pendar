لیگ پندار (سیستم امتیاز، لیگ ماهانه و جفت‌سازی مهارتی)

نصب:
1) فایل‌های این بسته را با همان مسیرها روی پروژه کپی کنید (جایگزینی فایل‌های موجود و افزودن فایل‌های جدید).
2) در ریشه‌ی مخزن:
   git checkout -b feature/pendar-league
   git add -A
   git commit -m "Add Pendar League: scoring, monthly leagues, quests, skill matchmaking"
   git push -u origin feature/pendar-league
3) در گیت‌هاب یک Pull Request به شاخه‌ی اصلی بسازید. Workflow به‌صورت خودکار تست‌های پایتون، Godot و سرور را اجرا می‌کند؛ بعد از سبز شدن Merge کنید تا نسخه‌ی وب منتشر شود.
4) سرور آنلاین (Liara یا هر جای دیگر) را هم دوباره دیپلوی کنید: پوشه‌ی online-server عوض شده است (جفت‌سازی بر اساس رتبه).
   کلاینت جدید با سرور قدیمی هم کار می‌کند (فقط حریف را بر اساس رتبه انتخاب نمی‌کند)، پس ترتیب دیپلوی مهم نیست.

بازیکنان فعلی: فایل ذخیره‌شان خودکار به نسخه‌ی جدید منتقل می‌شود و امتیازشان پاک نمی‌شود.
