# سرور صف انتظار Mind Bastion

این سرویس سبک Node.js برای بازی آنلاین وب است: بازیکن‌ها را با همان شناسه‌ی بازی در صف می‌گذارد، هر دو نفر را به یک اتاق وصل می‌کند و حرکت‌ها و ایموجی‌های مجاز را به حریف می‌رساند. کد مخفی فکر بکر هرگز از گوشی/مرورگر میزبان خارج نمی‌شود؛ سرور فقط طول کد و تعداد رنگ‌ها را به حدس‌زن می‌فرستد.

## اجرای محلی

```bash
npm install
npm test
npm start
```

سلامت سرویس: `http://localhost:3000/health` و WebSocket: `ws://localhost:3000/ws`.

## امنیت و محدودیت‌ها

- فقط فهرست بازی‌های شناخته‌شده و عملیات مجاز پذیرفته می‌شوند.
- ورودی‌ها اندازه محدود دارند؛ نام کاربری و ایموجی‌ها پاک‌سازی/محدود می‌شوند.
- این سرویس رله و صف انتظار است، نه داور کامل قواعد بازی. برای جلوگیری از تقلب جدی در بازی رقابتی باید منطق قواعد و اعتبارسنجی نوبت‌ها نیز روی سرور پیاده‌سازی شود.
- داده‌ی حساب کاربری/رمز عبور جمع‌آوری نمی‌شود؛ نام کاربری فقط نام نمایشی است.
- اتاق‌ها و صف‌ها حافظه‌ای هستند؛ با restart سرور، اتاق‌های فعال از بین می‌روند.

## استقرار در ایران

راهنمای فارسی اصلی در ریشه‌ی پروژه با نام `ONLINE_SERVER_FA.txt` قرار دارد. سرور Node.js آماده‌ی استقرار روی یک سرویس PaaS داخل ایران، مانند Liara، است. باید خودتان در حساب سرویس یک برنامه Node.js ایجاد کنید و در پوشه‌ی همین پروژه deploy انجام دهید. پس از استقرار، آدرس WSS صادرشده را در `project.godot` تنظیم کنید و دوباره نسخه‌ی وب را منتشر کنید.
