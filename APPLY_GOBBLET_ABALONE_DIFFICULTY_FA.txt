درجه سختی گابلت و ابلون

۱. محتوای این پوشه را در ریشه مخزن محلی جایگزین کنید؛ پوشه .git را نگه دارید.
۲. در Git Bash اجرا کنید:

git add main.gd games/gobblet/rules.gd games/gobblet/README.md games/abalone/rules.gd games/abalone/README.md tests/test_architecture.py APPLY_GOBBLET_ABALONE_DIFFICULTY_FA.txt
git commit -m "Add six difficulty levels to Gobblet and Abalone"
git push origin main

۳. اجرای Deploy Web App to GitHub Pages را در GitHub Actions بررسی کنید و پس از موفقیت صفحه را با Ctrl+F5 تازه‌سازی کنید.
