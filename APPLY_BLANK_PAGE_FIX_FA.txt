اصلاح صفحه خاکستری GitHub Pages
================================

علت: در games/abalone/rules.gd بدنه‌ی شرط `if not seen.has(key):` تورفتگی درست نداشت.
این خطای نحوی می‌توانست بارگذاری اسکریپت اصلی را متوقف و صفحه‌ی بازی را خالی کند.

تغییرات این بسته:
- اصلاح تورفتگی تولید فهرست حرکت‌های ابلون.
- افزودن بررسی تورفتگی بلوک‌های GDScript به tools/verify_structure.py.
- افزودن مرحله‌ی بررسی ساختار و smoke-test اجرای Godot به Deploy Web App to GitHub Pages.

برای انتشار:
1) محتویات MindBastion_Modular را روی ریشه‌ی مخزن محلی جایگزین کنید؛ پوشه‌ی .git را نگه دارید.
2) اجرا کنید:
   git add games/abalone/rules.gd tools/verify_structure.py .github/workflows/deploy-web.yml APPLY_BLANK_PAGE_FIX_FA.txt
   git commit -m "Fix blank web canvas caused by Abalone script parse error"
   git push origin main
3) در GitHub Actions منتظر Success بمانید. اگر بررسی startup خطایی پیدا کند، workflow قرمز می‌شود و دیگر نسخه‌ی خراب منتشر نخواهد شد.
4) پس از انتشار، صفحه را با Ctrl+F5 تازه کنید. اگر هنوز نسخه‌ی قدیمی دیده شد، DevTools > Application > Service Workers را باز کنید و Unregister بزنید، سپس صفحه را دوباره بارگذاری کنید.

توجه: تست اجرای Godot واقعی در محیط تهیه‌ی ZIP اجرا نشده است؛ اکنون این تست به‌صورت خودکار در CI اجرا می‌شود.
