افزودن درجه سختی به چهاربرگ و حکم
=================================

چه چیزی اضافه شده؟
- هر دو بازی در صفحه انتخاب حالت، شش سطح دارند: خیلی آسان، آسان، متوسط، سخت، استاد و استادتمام.
- هنگام بازی با کامپیوتر، سطح انتخاب‌شده در نشان «هوش CPU» دیده می‌شود.
- چهاربرگ: کامپیوتر بین گرفتن کارت‌ها، کارت‌های امتیازی، سور و میزان آسیب‌پذیری کارت‌های روی میز ارزیابی انجام می‌دهد.
- حکم: کامپیوتر کارت‌های مجاز، هزینه‌ی خرج کردن حکم، بردن دست و خال‌هایی را که حریف از آن‌ها خالی شده در تصمیم خود لحاظ می‌کند.

اعمال نسخه روی مخزن GitHub موجود:
1. ZIP را استخراج کن.
2. فایل‌های داخل پوشه‌ی Pendar را در پوشه‌ی محلی مخزن خودت کپی کن و فایل‌های هم‌نام را جایگزین کن.
3. پوشه‌ی .git موجود در مخزن خودت را حفظ کن؛ این بسته نیازی به جایگزین کردن آن ندارد.
4. در Git Bash، از ریشه‌ی مخزن، این دستورات را اجرا کن:

   git add main.gd games/pasoor/rules.gd games/hokm/rules.gd tests/test_architecture.py APPLY_PASOOR_HOKM_DIFFICULTY_FA.txt APPLY_DIFFICULTY_FIX_FA.txt
   git commit -m "Add six difficulty levels to Pasoor and Hokm"
   git push origin main

5. در GitHub بخش Actions را باز کن و منتظر بمان Deploy Web App to GitHub Pages با وضعیت Success تمام شود.
6. صفحه‌ی بازی را با Ctrl+F5 تازه‌سازی کن. از منوی هر بازی سطح سختی را انتخاب کن و گزینه‌ی بازی با کامپیوتر را بزن.

آزمایش انجام‌شده:
- 9 تست Python پروژه پاس شده‌اند.
- بررسی ساختاری پروژه پاس شده است.
- محیط فعلی Godot برای اجرای تست واقعی موتور در دسترس نبود؛ انتشار نهایی پس از Push و موفقیت GitHub Actions مشخص می‌شود.
