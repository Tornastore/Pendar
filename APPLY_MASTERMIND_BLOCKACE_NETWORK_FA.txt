اصلاحات فکر بکر و بلاک‌آس
===========================

1) این نسخه را در ریشه مخزن محلی جایگزین کنید و پوشه .git خودتان را نگه دارید.
2) فکر بکر: بازی با کامپیوتر یا دو گوشی از طریق IP؛ طول کد و تعداد رنگ در درجه‌های ۱ تا ۶ هر دو از ۴ تا ۹ می‌روند. نشان هر رنگ دقیقاً زیر همان خانه‌ی حدس است. کد مخفی فقط روی میزبان می‌ماند.
3) بلاک‌آس: حالت اصلی Blokus Duo با ۲۱ قطعه‌ی استاندارد، قوانین اتصال گوشه/لبه، امتیازدهی، ۶ سطح هوش CPU و بازی شبکه‌ای از طریق IP.
4) برای شبکه: هر دو گوشی را به یک Wi-Fi وصل کنید. یک گوشی «میزبانی روی وای‌فای» را بزند و IP را به گوشی دیگر بدهد؛ گوشی دوم همان بازی را انتخاب کند و «اتصال با IP» را بزند. میزبان از لابی بازی را شروع کند. اگر روتر جداسازی دستگاه‌ها را فعال کرده یا فایروال پورت UDP 7777 را بسته باشد، اتصال انجام نمی‌شود.
5) این اتصال ENet/UDP فقط در خروجی بومی Android/Desktop کار می‌کند، نه در مرورگر GitHub Pages. برای بازی با IP روی گوشی‌ها، APK را بسازید و نصب کنید.
6) پس از جایگزینی فایل‌ها، در Git Bash از ریشه مخزن این دستورات را اجرا کنید:
   git add -A
   git commit -m "Add IP multiplayer to Mastermind and Blokus Duo"
   git push origin main
   سپس در GitHub Actions اجرای Deploy Web App را برای نسخه وب بررسی کنید.
