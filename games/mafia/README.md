# مافیا کلاسیک

سناریوی پایه و شناخته‌شده‌ی مافیا: مافیا، کارآگاه، دکتر و شهروندان. گرداننده به‌صورت خودکار کار می‌کند و جزو بازیکنان نیست. در شب، مافیا هدف انتخاب می‌کند، دکتر یک نفر را محافظت می‌کند و کارآگاه یک نفر را بررسی می‌کند. در روز، بازیکنان پس از گفت‌وگوی بیرون از برنامه یا با واکنش‌های موجود رأی می‌دهند. نقش بازیکن حذف‌شده آشکار می‌شود.

ترکیب نقش‌ها: ۶ نفر = ۱ مافیا؛ ۷ تا ۹ نفر = ۲ مافیا؛ ۱۰ تا ۱۲ نفر = ۳ مافیا. در هر بازی یک کارآگاه و یک دکتر وجود دارد؛ باقی شهروند ساده‌اند. بازی با ۶ تا ۱۲ نفر انجام می‌شود.

- CPU با شش درجه‌ی توان تصمیم‌گیری؛ LAN/IP و صف آنلاین گروهی.
- نقش هر بازیکن در رابط فقط به خود او نشان داده می‌شود و نتیجه‌ی بررسی کارآگاه خصوصی است. برای گفت‌وگوی زنده‌ی انسانی، از مکالمه‌ی بیرون از برنامه استفاده کنید؛ سرور فعلی چت متنی ندارد.
- برای بازی آنلاینِ جدی با نقش‌های مخفی، پردازش کاملاً امن نقش‌ها باید سمت سرور authoritative انجام شود؛ این نسخه روی کلاینت‌ها همگام‌سازی می‌کند و برای بازی دوستانه طراحی شده است.
