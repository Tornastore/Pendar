# شطرنج

- شناسه ماژول: `chess`
- پیاده‌سازی قوانین و مالکیت state این بازی در `rules.gd` قرار دارد.
- رابط کاربری مشترک فعلاً از طریق adapter در برنامه اصلی به state دسترسی دارد؛ قوانین از کد رابط جدا شده‌اند.
- برای تغییر قوانین این بازی، در درجه اول همین ماژول را ویرایش کنید.


## هوش مصنوعی شش‌سطحی

- موتور مستقل هوش در `ai.gd` قرار دارد.
- سطح ۱ حرکت تصادفی، سطح ۲ انتخاب حریصانه بر اساس ارزش و موقعیت، و سطح‌های ۳ تا ۶ جست‌وجوی افزایشی با هرس آلفا–بتا دارند.
- سطح‌های بالاتر عمق و بودجهٔ جست‌وجوی بیشتری دارند.
- نکته: این AI از قوانین فعلی پروژه استفاده می‌کند؛ شطرنج پروژه هنوز قوانین کامل رسمی مانند قلعه‌رفتن، آن‌پاسان و جلوگیری از حرکت شاه به کیش را پیاده‌سازی نکرده و برد فعلی با گرفتن شاه تشخیص داده می‌شود.
