# فکر بکر (Mastermind)

- شناسه ماژول: `mastermind`
- شش درجه سختی: هر سطح یک خانه به کد مخفی و یک رنگ قابل‌استفاده اضافه می‌کند؛ از ۴ خانه/۴ رنگ تا ۹ خانه/۹ رنگ.
- حالت تک‌نفره: کامپیوتر کد را می‌سازد و بازیکن حداکثر ۱۰ تلاش دارد؛ تکرار رنگ مجاز است.
- حالت دو نفره شبکه‌ای: میزبان از گزینه «میزبانی روی وای‌فای» استفاده می‌کند، کد مخفی را روی دستگاه خودش ثبت می‌کند و بازیکن دوم با IP میزبان وصل می‌شود تا حدس بزند. خود کد مخفی هرگز به دستگاه مهمان ارسال نمی‌شود؛ فقط بازخورد حدس‌ها همگام می‌شود.
- نشان سیاه/سفید دقیقاً زیر مهره‌ی متناظر در همان جای ردیف حدس قرار می‌گیرد: سیاه یعنی رنگ و جای درست؛ سفید یعنی رنگ در کد وجود دارد اما در جای دیگری است. مهره‌های تکراری بدون دوباره‌شماری ارزیابی می‌شوند.
- IP/LAN از طریق ENet در خروجی‌های بومی Android/Desktop پشتیبانی می‌شود و هر دو گوشی باید روی یک شبکه‌ی Wi-Fi باشند. صفحه‌ی GitHub Pages در مرورگر نمی‌تواند از ENet/UDP استفاده کند؛ در نسخه‌ی وب دکمه‌های شبکه‌ای غیرفعال می‌مانند.
- منطق بازی در `rules.gd` و ناوبری و RPCها در `main.gd` است.


## مسابقه‌ی چهار نفره با CPU

- «مسابقه با ۳ CPU» را انتخاب کنید؛ هر CPU کد را به‌صورت مستقل حل می‌کند.
- برای حریفان فقط پیشرفت، تعداد جایگاه‌های دقیق و رتبه نمایش داده می‌شود، نه حدس‌های خصوصی آن‌ها.
- درجه‌ی سختی هم طول کد/تعداد رنگ‌ها و هم روش نمونه‌گیری و ارزیابی حدس CPU را تغییر می‌دهد.
