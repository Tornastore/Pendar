# چهاربرگ (پاسور)

- شناسه ماژول: `pasoor`
- پیاده‌سازی قوانین و مالکیت state این بازی در `rules.gd` قرار دارد.
- رابط کاربری مشترک فعلاً از طریق adapter در برنامه اصلی به state دسترسی دارد؛ قوانین از کد رابط جدا شده‌اند.
- برای تغییر قوانین این بازی، در درجه اول همین ماژول را ویرایش کنید.

## مسئولیت ماژول‌ها

`presentation.gd` چیدمان دست و میز، برجسته‌سازی کارت‌های گرفته‌شدنی، دکمهٔ تأیید و تبدیل لمس به انتخاب کارت را مدیریت می‌کند. محاسبهٔ گرفتن، سور، امتیاز، نوبت، CPU و شبکه در `rules.gd` باقی می‌مانند.
