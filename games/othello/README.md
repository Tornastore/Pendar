# اتلو

- شناسه ماژول: `othello`
- پیاده‌سازی قوانین و مالکیت state این بازی در `rules.gd` قرار دارد.
- رابط کاربری مشترک فعلاً از طریق adapter در برنامه اصلی به state دسترسی دارد؛ قوانین از کد رابط جدا شده‌اند.
- برای تغییر قوانین این بازی، در درجه اول همین ماژول را ویرایش کنید.

- هوش کامپیوتر در `ai.gd` قرار دارد و شش سطح سختی را برای هر دو صفحهٔ ۸×۸ و ۱۲×۱۲ ارائه می‌کند. سطح‌ها از انتخاب حریصانه تا جست‌وجوی چندمرحله‌ای آلفا–بتا با ارزیابی گوشه‌ها، موقعیت، تحرک و مهره‌های مرزی متفاوت‌اند. برای صفحهٔ ۱۲×۱۲ بودجهٔ جست‌وجو محدودتر است تا پاسخ‌گویی حفظ شود.
