# گابلت

- شناسه ماژول: `gobblet`
- هر بازیکن ۱۲ مهره دارد: سه مهره از هرکدام از چهار اندازه‌ی کوچک، متوسط، بزرگ و خیلی بزرگ.
- در هر نوبت می‌توان مهره‌ی تازه را روی خانه‌ی خالی گذاشت؛ فقط برای قطع‌کردن ردیف سه‌تایی حریف می‌توان مهره‌ی تازه را روی مهره‌ی نمایان حریف گذاشت.
- همچنین می‌توان بالاترین مهره‌ی خود روی صفحه را به هر خانه‌ی مجاز منتقل کرد؛ مقصد باید خالی باشد یا مهره‌ی نمایان کوچک‌تری داشته باشد.
- ردیف چهارتایی بر اساس مهره‌های نمایان تشخیص داده می‌شود. اگر حرکت با آشکارکردن مهره‌های زیرین، ردیف چهارتایی حریف را باقی بگذارد، بازیکن حرکت‌کننده می‌بازد؛ مگر اینکه همان حرکت آن ردیف را بپوشاند.
- کنترل: برای گذاشتن مهره، اندازه را از پایین انتخاب و خانه‌ی روشن را بزنید. برای حرکت، ابتدا بالاترین مهره‌ی خود روی صفحه و سپس خانه‌ی مقصد روشن را بزنید.
- پیاده‌سازی منطق بازی در `rules.gd` قرار دارد.

- درجه‌ی هوش کامپیوتر ۶ سطح دارد: از انتخاب نسبتاً تصادفی تا ارزیابی پاسخ احتمالی حریف؛ سطح از منوی پیش از بازی انتخاب می‌شود.
