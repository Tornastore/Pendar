# حکم

- وضعیت انتشار: نسخهٔ عمومی و فعال؛ برچسب آزمایشی ندارد.

- شناسه ماژول: `hokm`
- پیاده‌سازی قوانین و مالکیت state این بازی در `rules.gd` قرار دارد.
- رابط کاربری مشترک فعلاً از طریق adapter در برنامه اصلی به state دسترسی دارد؛ قوانین از کد رابط جدا شده‌اند.
- برای تغییر قوانین این بازی، در درجه اول همین ماژول را ویرایش کنید.

## مسئولیت ماژول‌ها

`presentation.gd` چیدمان دست و کارت‌های بازی‌شده و تبدیل لمس به شاخص کارت را مدیریت می‌کند. اعتبار خال، بردن دست، امتیاز، تاریخچهٔ کارت‌ها، CPU و شبکه در `rules.gd` باقی می‌مانند.
