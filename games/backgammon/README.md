# تخته‌نرد

- شناسه ماژول: `backgammon`
- پیاده‌سازی قوانین و مالکیت state این بازی در `rules.gd` قرار دارد.
- رابط کاربری مشترک فعلاً از طریق adapter در برنامه اصلی به state دسترسی دارد؛ قوانین از کد رابط جدا شده‌اند.
- برای تغییر قوانین این بازی، در درجه اول همین ماژول را ویرایش کنید.


## هوش مصنوعی شش‌سطحی

- موتور مستقل هوش در `ai.gd` قرار دارد.
- سطح ۱ حرکت تصادفی، سطح ۲ انتخاب حریصانه و سطح‌های ۳ تا ۶ جست‌وجوی توالی تاس‌های همان نوبت با اولویت‌بندی متفاوت دارند.
- ارزیابی سطح‌های بالاتر پیشروی (pip race)، بیرون‌بردن، زدن تک‌مهره، مهره‌های تک‌افتاده و خانه‌های بسته را لحاظ می‌کند.
- نکته: هوش با مدل فعلی بازی سازگار است؛ قوانین تخته‌نرد در پروژه هنوز نسخهٔ ساده‌شده‌اند و بازگرداندن مهره از بار (bar re-entry) کامل پیاده‌سازی نشده است.
