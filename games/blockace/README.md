# بلاک‌آس (Blokus Duo)

- شناسه ماژول: `blockace`
- نسخه اصلی فعال است (برچسب آزمایشی حذف شده) و بازی دو نفره دارد.
- صفحه ۱۴×۱۴ و ۲۱ قطعه استاندارد برای هر بازیکن: تک‌خانه، دومینو، ۲ سه‌خانه‌ای، ۵ چهارخانه‌ای و ۱۲ پنج‌خانه‌ای. چرخش و وارونه‌کردن قطعه مجاز است.
- قطعه اول باید خانه شروع مشخص‌شده‌ی هر بازیکن را بپوشاند. هر قطعه بعدی باید از گوشه به قطعه هم‌رنگ متصل شود و نباید از ضلع با قطعه هم‌رنگ تماس داشته باشد؛ تماس با قطعات حریف آزاد است.
- امتیاز نهایی: به ازای خانه‌های قطعات استفاده‌نشده امتیاز منفی؛ استفاده از همه قطعات ۱۵ امتیاز پاداش و اگر قطعه تک‌خانه‌ای آخرین قطعه باشد ۵ امتیاز اضافه. برنده با امتیاز نهایی تعیین می‌شود.
- شش درجه‌ی سختی CPU در منوی حالت بازی قابل انتخاب است. سطح بالاتر انتخاب قطعه‌های بزرگ‌تر و گسترش موقعیت را بهتر اولویت‌بندی می‌کند.
- حالت دو نفره شبکه‌ای با «میزبانی روی وای‌فای» و «اتصال با IP» فعال است. برای IP، بازی را روی خروجی بومی Android/Desktop اجرا کنید؛ مرورگر GitHub Pages از ENet/UDP پشتیبانی نمی‌کند.
