# دوز چهار‌تایی — Connect Four

نسخه‌ی استاندارد ۷ ستون × ۶ ردیف. هر حرکت یک مهره را از بالای ستون می‌اندازد؛ چهار مهره‌ی هم‌رنگ به‌صورت افقی، عمودی یا مورب برنده است. در نبود خط چهار‌تایی و پرشدن صفحه، بازی مساوی می‌شود.

- دو بازیکن؛ بازی مقابل CPU یا حریف از طریق LAN/IP و صف آنلاین.
- شش درجه‌ی CPU با جست‌وجوی minimax و هرس آلفا-بتا.
- نتیجه در پنجره‌ی روی صفحه نشان داده می‌شود و صفحه‌ی پایانی باقی می‌ماند.
