# فونت فارسی پروژه

رابط Pendar از فونت **Vazirmatn** برای نمایش سازگارتر متن فارسی استفاده می‌کند. فایل‌های Regular و Bold در زمان اجرای workflowهای ساخت Web و APK از منبع رسمی پروژه دریافت می‌شوند و عمداً به‌صورت فایل باینری داخل مخزن نگهداری نمی‌شوند.

برای اجرای محلی در Godot، از صفحه‌ی رسمی فونت فایل‌های زیر را دریافت و در همین پوشه قرار دهید:

- `Vazirmatn-Regular.ttf`
- `Vazirmatn-Bold.ttf`

منبع رسمی: https://github.com/rastikerdar/vazirmatn
مجوز: SIL Open Font License 1.1. فایل `OFL.txt` نیز هنگام ساخت Web/APK کنار فونت دریافت و در خروجی قرار می‌گیرد.

اگر فایل‌ها در دسترس نباشند، برنامه از فونت‌های فارسی نصب‌شده روی سیستم استفاده می‌کند؛ در این حالت ظاهر متن ممکن است میان دستگاه‌ها تفاوت داشته باشد.
