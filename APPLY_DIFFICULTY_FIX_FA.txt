راهنمای اعمال اصلاح درجه سختی پنتاگو و دومینو
=============================================

این نسخه سه مورد را اصلاح می‌کند:
- عنوان انتخاب شش درجه سختی در صفحه حالت بازی برای پنتاگو و دومینو نمایش داده می‌شود.
- سطح انتخاب‌شده در زمان بازی با کامپیوتر با نشان «هوش CPU» داخل بازی دیده می‌شود.
- تست ساختاری اطمینان می‌دهد که کنترل درجه سختی به AI هر دو بازی متصل مانده باشد.

مهم: فقط اجرای مجدد GitHub Actions فایل‌های کد را به مخزن ارسال نمی‌کند. باید فایل‌ها را جایگزین کنی و Push انجام بدهی.

مراحل:
1. ZIP را باز کن.
2. محتوای پوشه Pendar را روی پوشه محلی مخزن خودت کپی کن و فایل‌های هم‌نام را جایگزین کن. پوشه .git پروژه محلی خودت را حذف یا جایگزین نکن.
3. در Git Bash، داخل پوشه اصلی مخزن این دستورات را اجرا کن:

   git add main.gd games/pentago games/domino .github/workflows README.md tests/test_architecture.py APPLY_DIFFICULTY_FIX_FA.txt
   git commit -m "Fix Pentago and Domino difficulty UI and AI"
   git push origin main

4. به GitHub → Actions برو و منتظر اجرای Deploy Web App to GitHub Pages بمان تا سبز (Success) شود.
5. سایت منتشرشده را با Ctrl+F5 تازه‌سازی کن. وارد پنتاگو یا دومینو شو؛ شش گزینه باید در صفحه انتخاب حالت باشند و پس از شروع بازی، سطح فعال با نشان «هوش CPU» دیده شود.

اگر git commit پیام «nothing to commit» داد، یعنی فایل‌های جدید در پوشه مخزن جایگزین نشده‌اند یا ZIP در مسیر اشتباه باز شده است.

تست‌های ساختاری با Python اجرا می‌شوند:
   python tools/verify_structure.py
   pytest -q

توجه: تست‌های ساختاری جای تست واقعی اجرای بازی با Godot را نمی‌گیرند؛ برای تأیید نهایی، اجرای Workflow انتشار هم باید موفق باشد.


به‌روزرسانی درجه سختی چهاربرگ و حکم:
- در صفحه انتخاب حالتِ هر بازی، یکی از شش سطح درجه سختی را انتخاب کنید.
- سطح انتخاب‌شده به عنوان «هوش CPU» هنگام بازی با کامپیوتر نمایش داده می‌شود.
- در چهاربرگ، سطوح بالا ارزش کارت‌ها، احتمال گرفتن دوباره‌ی کارت‌های روی میز و ساختن سور را ارزیابی می‌کنند.
- در حکم، سطوح بالا انتخاب کارت برای بردن/از دست دادن دست، حفظ حکم و خال‌های خالی‌شده‌ی حریف را در نظر می‌گیرند.
- برای انتشار تغییرات، این فایل‌ها را به شاخه main ارسال کنید؛ فقط Re-run کردن Actions کد جدید را به مخزن اضافه نمی‌کند.
