اصلاح قوانین گابلت و ابلون

این بسته شامل اصلاح قوانین واقعی دو بازی است:

گابلت:
- جابه‌جایی بالاترین مهره‌ی خود روی صفحه به هر خانه‌ی خالی یا روی مهره‌ی کوچک‌تر.
- ارزیابی برد و باخت بر اساس مهره‌های نمایان پس از کامل‌شدن حرکت.
- اگر حرکت مهره‌ای را بردارد و ردیف چهارتایی حریف را آشکار کند، بازیکن حرکت‌کننده می‌بازد؛ مگر اینکه مقصد همان حرکت یکی از مهره‌های آن خط را بپوشاند.
- هوش کامپیوتر امکان حرکت مهره‌های روی صفحه را نیز دارد.

ابلون:
- صفحه‌ی شش‌ضلعی استاندارد با ۶۱ خانه و ۱۴ مهره برای هر بازیکن.
- انتخاب و حرکت یک تا سه مهره‌ی هم‌رنگ و هم‌راستا.
- حرکت مستقیم و حرکت پهلو.
- قانون Sumito: هل‌دادن فقط با برتری عددی ۲ به ۱، ۳ به ۱ یا ۳ به ۲؛ حرکت پهلو امکان هل‌دادن ندارد.
- حذف مهره‌ای که از لبه بیرون رانده می‌شود و پایان بازی با بیرون‌رفتن ششمین مهره‌ی حریف.
- تنظیم وضعیت بازی در منو از حالت آزمایشی به وضعیت عادی.

اعمال روی GitHub:
1) ZIP را استخراج کنید.
2) محتویات پوشه‌ی MindBastion_Modular را در پوشه‌ی مخزن محلی جایگزین کنید؛ پوشه‌ی .git خود را نگه دارید.
3) از ریشه‌ی پروژه در Git Bash اجرا کنید:

   git add main.gd core/game_catalog.gd games/gobblet/rules.gd games/gobblet/README.md games/abalone/rules.gd games/abalone/README.md tests/test_architecture.py APPLY_GOBBLET_ABALONE_RULES_FA.txt
   git commit -m "Implement Gobblet movement and full Abalone rules"
   git push origin main

4) در GitHub Actions نتیجه‌ی Deploy Web App to GitHub Pages را بررسی کنید.
