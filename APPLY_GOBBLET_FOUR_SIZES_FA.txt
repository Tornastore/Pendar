اصلاح گابلت: چهار اندازه مهره
=================================

در این نسخه، بازی گابلت چهار اندازه مهره دارد: کوچک، متوسط، بزرگ و خیلی بزرگ.
هر بازیکن ۳ مهره از هر اندازه (در مجموع ۱۲ مهره) دریافت می‌کند. اندازه چهارم
در قوانین مجاز بودن حرکت، موجودی مهره‌ها، نوبت کامپیوتر، نمایش صفحه و راهنمای بازی
اعمال شده است. چهار کارت انتخاب اندازه در صفحه موبایل به شکل ۲×۲ قرار گرفته‌اند.

برای به‌روزرسانی مخزن محلی:
1. از ZIP، محتویات پوشه Pendar را روی ریشه پروژه محلی کپی کنید.
2. فایل‌های هم‌نام را جایگزین کنید؛ پوشه .git را حذف نکنید.
3. در Git Bash از ریشه پروژه اجرا کنید:

   git add games/gobblet/rules.gd games/gobblet/README.md main.gd tests/test_architecture.py APPLY_GOBBLET_FOUR_SIZES_FA.txt
   git commit -m "Fix Gobblet four piece sizes"
   git push origin main

برای انتشار نسخه وب، اجرای Deploy Web App to GitHub Pages را در GitHub Actions بررسی کنید.
این بررسی‌ها تست ساختاری و ایستا هستند؛ اجرای واقعی موتور Godot باید جداگانه تأیید شود.
