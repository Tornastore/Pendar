# اصلاحات رابط، برج هیجان و هوش مصنوعی کوریدور

این بسته برای اعمال روی شاخهٔ فعلی `feature/pendar-league` آماده شده است.

## تغییرات

- تصویرهای منویی اختصاصی و رسم‌شده در موتور برای دوز چهار‌تایی، برج هیجان و مافیا اضافه شده‌اند؛ نیازی به فایل تصویر خارجی نیست.
- برج هیجان به نمای ایزومتریک شبه‌سه‌بعدی تبدیل شده و سه نمای روبه‌رو، کناری و بالا را نشان می‌دهد. لمس با چندضلعی واقعی وجه‌های رسم‌شده تطبیق داده می‌شود تا لمس یک بلوک به اشتباه بلوک پشت آن را انتخاب نکند.
- راهنمای برج هیجان توضیح می‌دهد که ظاهر شبه‌سه‌بعدی است و فروپاشی همچنان با مدل قواعد بازی محاسبه می‌شود؛ شبیه‌سازی فیزیکی سه‌بعدی واقعی اضافه نشده است.
- شکست خطوط راهنما و اندازه‌گیری ارتفاع از یک الگوریتم مشترک استفاده می‌کنند؛ حتی کلمه‌های بسیار عریض هم در صورت نیاز می‌شکنند.
- متن وضعیت و اتفاق‌های مافیا فشرده و اندازه‌گذاری می‌شوند؛ پاورقی قبلی که با دکمه‌های ثابت پایین صفحه هم‌پوشانی داشت حذف شده است.
- هوش مصنوعی کوریدور پیش از حرکت برد فوری را می‌گیرد، جلوی برد قطعی حریف را با دیوار قانونی می‌گیرد، در سطح‌های متوسط پاسخ حریف را شبیه‌سازی می‌کند و در سطح‌های بالاتر جست‌وجوی عمیق‌تر/پهن‌تری دارد.

## آزمون‌های اجراشده

- `python -m pytest -q --basetemp=/tmp/pendar-pytest` — ۱۵۳ تست و ۳۱ زیرآزمون موفق
- `python tools/verify_structure.py` — بررسی ساختاری موفق
- `node --test online-server/test/protocol.test.js` — هر ۱۴ آزمون موفق

در این محیط موتور Godot اجرا نشد؛ بنابراین بعد از اعمال Patch، آزمون بارگذاری و اجرای headless را با Godot نصب‌شده روی دستگاه خود اجرا کنید.

## اعمال روی مخزن فعلی

در Git Bash از ریشهٔ پروژه:

```bash
git status --short
git apply --check PENDAR_UI_JENGA_QUORIDOR_FIXES.patch
git apply PENDAR_UI_JENGA_QUORIDOR_FIXES.patch
python -m pytest -q --basetemp=./.pytest-temp-pendar
python tools/verify_structure.py
node --test online-server/test/protocol.test.js
```

اگر آزمون‌ها موفق شدند:

```bash
git add -A
git diff --cached --check
git commit -m "Fix UI wrapping Jenga and Quoridor AI"
git push
```

این Commit روی شاخهٔ فعلی ثبت می‌شود؛ برای وارد کردنش به `main` بعداً Pull Request بسازید.
