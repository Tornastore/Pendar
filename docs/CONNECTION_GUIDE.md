# راهنمای اتصال دو گوشی (Mind Bastion)

اتصال مستقیم LAN با **IP محلی** از پورت **7777/UDP (ENet)** در APK/Desktop باقی مانده است. برای نسخه وب یا اتصال بازیکن‌ها از شبکه‌های مختلف، سرور matchmaking مبتنی بر **WSS** استفاده می‌شود؛ راه‌اندازی آن در `ONLINE_SERVER_FA.txt` است. تا زمان میزبانی سرور و قرار دادن آدرس واقعی در `project.godot`، بازی آنلاین وب آماده اتصال نخواهد بود.

## قبل از شروع (چک‌لیست)
- [ ] هر دو گوشی به **یک وای‌فای** وصل‌اند، یا یکی hotspot روشن کرده و دیگری به آن وصل است
- [ ] VPN روی هر دو گوشی **خاموش** است
- [ ] نسخه‌ی بازی روی هر دو گوشی یکسان است
- [ ] برای اتصال بدون مودم، روی یک گوشی هات‌اسپات روشن کن و گوشی دوم را به آن وصل کن

## مراحل
### گوشی میزبان (Host)
1. بازی را انتخاب کن و گزینه‌ی **میزبانی روی وای‌فای** را بزن.
2. صفحه‌ی لابی باز می‌شود و IP نمایش داده می‌شود (مثلاً `192.168.1.23`).
3. منتظر بمان تا حریف وصل شود، سپس بازی را شروع کن.

### گوشی مهمان (Client)
1. همان بازی را انتخاب کن و گزینه‌ی **اتصال با IP** را بزن.
2. IP میزبان را **کامل** وارد کن (چهار بخش با نقطه).
3. پیام «متصل شدید!» را که دیدی، منتظر شروع بازی توسط میزبان بمان.

## پیدا کردن IP درست
- اگر IP نمایش‌داده‌شده کار نکرد: `تنظیمات ← وای‌فای ← (شبکه‌ی متصل) ← جزئیات` و آدرس IP را بخوان.
- اگر میزبان hotspot است، IP معمولاً `192.168.43.1` یا شبیه `192.168.x.1` است.
- IP باید با `192.168.` یا `10.` یا `172.` شروع شود. آدرس‌های دیگر (دیتای موبایل) درست نیستند.

## رفع خطاها
| پیام | معنی | راه‌حل |
|---|---|---|
| **خطا در اتصال (کد ...)** | برنامه نتوانست اتصال را شروع کند | نسخه‌ی آخر بازی را روی هر دو گوشی نصب کن و IP را کامل وارد کن. اگر باز هم آمد، کد داخل پرانتز را برای سازنده بفرست |
| **اتصال ناموفق بود؛ IP و یکسان بودن وای‌فای را بررسی کنید** | IP معتبر است ولی بسته نرسید | هر دو در یک شبکه باشند؛ VPN خاموش؛ «AP/Client Isolation» روتر را خاموش کن؛ یا از hotspot استفاده کن |
| **خطا در ایجاد سرور (پورت اشغال؟)** | پورت 7777 در دسترس نیست | بازی را کامل ببند و دوباره باز کن |
| **ظرفیت پر است** | تعداد بازیکنان به حد مجاز رسیده | بازیکن اضافه را قطع کن |

## اگر باز هم وصل نشد
1. هر دو گوشی را از وای‌فای قطع و دوباره وصل کن.
2. روتر را رها کن و یک گوشی را hotspot کن (ساده‌ترین راه، چون isolation ندارد).
3. بازی را روی هر دو گوشی کامل ببند و دوباره باز کن.
4. میزبان را عوض کن (گوشی دیگر میزبان شود).

## بازی‌هایی با نقش ویژه
- **فکر بکر:** میزبان کد مخفی را می‌چیند و ثبت می‌کند؛ مهمان حدس می‌زند. کد مخفی به مهمان ارسال نمی‌شود، فقط نتایج هر حدس همگام می‌شود. درجه‌ی سختی طول کد و تعداد رنگ‌ها را با هم افزایش می‌دهد.
- **بلاک‌آس:** هر دو گوشی روی صفحه‌ی ۱۴×۱۴ نوبتی قطعه می‌گذارند؛ میزبان شروع بازی را کنترل می‌کند و سطح CPU فقط روی حالت تک‌نفره اثر دارد.


## صف انتظار آنلاین در نسخه وب
1. ابتدا سرور را طبق `ONLINE_SERVER_FA.txt` روی Liara یا سرویس Node.js قابل‌دسترسی برای کاربران مستقر کنید.
2. در بازی «آنلاین» را بزنید، نام کاربری را ذخیره کنید و یک بازی مشخص انتخاب کنید.
3. روی «جستجوی هم‌بازی آنلاین» بزنید؛ اگر حریف دیگری همان بازی را انتخاب کرده باشد، هر دو به‌طور خودکار متصل می‌شوند.
4. داخل بازی دکمه 😊 ایموجی‌های مجاز را باز می‌کند.
