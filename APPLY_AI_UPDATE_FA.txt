۱) این ZIP را مستقیم داخل ریشهٔ پوشه فعلی مخزن خود استخراج کنید؛ فایل‌های هم‌نام را جایگزین کنید. ساختار مسیرها در این ZIP از ریشهٔ مخزن شروع می‌شود.
۲) فایل‌های GitHub Actions و export_presets.cfg عمداً داخل این بسته نیستند تا اصلاح فونت وب و تنظیمات موجود دست‌نخورده بمانند.
۳) در Git Bash اجرا کنید:
   python -m pytest tests -q
   python tools/verify_structure.py
   git diff --check
   git status --short
۴) پس از دیدن فهرست تغییرات، فایل‌های جدید و تغییرکرده را add، commit و push کنید.
