بازنگری هوش مصنوعی Pendar — شش سطح، با تمرکز بر استاد و استادتمام

تغییرات اصلی:
- شطرنج: جست‌وجوی تاکتیکی quiescence، جدول transposition با boundهای alpha-beta، مرتب‌سازی حرکت بر اساس بهترین حرکت ذخیره‌شده و تقسیم بودجه بین حرکت‌های ریشه.
- اتلو: جست‌وجوی عمیق‌تر، جدول transposition، ارزیابی تحرک بالقوه و لبه‌های پایدار، و اصلاح پایان‌بازی دقیق ۸×۸.
- کریدور: جست‌وجوی خصمانه برای سطح استاد، جریمه‌ی چرخه و بازدید مجدد.
- تخته‌نرد: بیشینه‌سازی تعداد تاس‌های قانونی پیش از ارزیابی موقعیت، بررسی هر دو ترتیب تاس و ارزیابی برد/باخت قطعی و پرایم.
- گابلت/ابلون/بلاک‌آس: نگاه به پاسخ‌های برتر حریف و ادامه‌های محتمل.
- دومینو/حکم/چهاربرگ/پنتاگو: ارزیابی ادامه‌ی دست، نمونه‌گیری اطلاعات پنهان، خطر گرفتن و تهدیدهای برد فوری.
- رفع یک خط prose بدون کامنت در فایل حکم.

نصب:
1. ZIP را استخراج و محتویات Pendar را در ریشه‌ی مخزن محلی جایگزین کنید؛ .git را نگه دارید.
2. اجرا کنید:
   python -m pytest -q
   python tools/verify_structure.py
   git diff --check
3. سپس:
   git add -A
   git commit -m "Strengthen expert and grandmaster AI across games"
   git push origin main
4. در GitHub Actions منتظر موفقیت Build/Deploy بمانید.

محدودیت بررسی: در این محیط Godot 4.3 اجرا نشد؛ تست‌های Python و بررسی ساختاری جایگزین تست زنده‌ی موتور نیستند. اجرای Workflow ساخت Godot برای تأیید نهایی الزامی است.
