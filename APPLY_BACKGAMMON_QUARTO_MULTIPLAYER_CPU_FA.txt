اصلاح تخته‌نرد، مهره‌های کوارتو و حالت CPU چندنفره

محتویات این بسته کل پروژه‌ی Pendar است. برای اعمال آن:
1. ZIP را استخراج کنید.
2. محتویات پوشه‌ی Pendar را روی پوشه‌ی محلی مخزن خود کپی و فایل‌های هم‌نام را جایگزین کنید.
3. پوشه‌ی .git محلی خود را نگه دارید.
4. از ریشه‌ی مخزن اجرا کنید:
   git add -A
   git commit -m "Improve backgammon AI and Quarto pieces"
   git push origin main
5. در GitHub Actions، موفقیت Deploy Web App to GitHub Pages را بررسی کنید.

تغییرها:
- تخته‌نرد در کاتالوگ حالت آزمایشی ندارد.
- شروع با دو تاس غیرمساوی؛ دارنده‌ی تاس بزرگ‌تر شروع می‌کند.
- شش سطح CPU از انتخاب تصادفی میان حرکت‌های مجاز تا ارزیابی تاکتیکی قوی‌تر؛ انتخاب هر حرکت از مجموعه‌ی مجازِ رعایت‌کننده‌ی بیشترین تعداد تاس انجام می‌شود.
- وضعیت CPU در نوار بالای تخته‌نرد نشان داده می‌شود؛ برنده/بازنده در پنجره‌ی نتیجه نیز تشخیص داده می‌شود.
- مسیر حرکت و پایان نوبت تخته‌نرد از مسیر شبکه‌ای/LAN/WebSocket عبور می‌کند.
- مهره‌های Quarto به شکل‌های واضح‌تر استاندارد: بلند/کوتاه، گرد/مربع، روشن/تیره و توپر/توخالی.
- بازی‌های فعلی بالای دو نفره که پشتیبانی می‌شوند، حالت مقابل CPU دارند: Quoridor چهارنفره مقابل سه CPU و مسابقه‌ی Mastermind مقابل سه CPU.
